How to set it up

  1. Click Download above. The file is FX_Tweaks.bat.
  2. Open it from your Downloads folder.
  3. If Windows says “Windows protected your PC”, click More info, then Run anyway.
  4. Click Yes when it asks to allow changes.
  5. Make an account, then run Boost now before you play.

⚠ If it won’t open at all (Smart App Control)

Some PCs have Smart App Control turned on. It blocks the app with an OK button and no way to run it. If that happens:

  1. Press the Windows key and type Smart App Control.
  2. Open the Smart App Control setting.
  3. Switch it from On to Off.
  4. Download and open FX Tweaks again.

Important: Smart App Control can’t be turned on again later without resetting Windows — Microsoft made it one-way on purpose. Only turn it off if you trust the app. If you’d rather not, that’s okay; you just can’t run FX Tweaks on that PC.

FX Tweaks changes Windows settings and can be fully undone with Undo all inside the app.
